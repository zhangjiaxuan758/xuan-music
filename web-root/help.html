小轩音乐 · 使用与问题排查

版本 1.6.5 · 最近更新 2026-11

登录

打开应用后在首页点「登录网易云账号」，用网易云 App 扫码即可。扫码后如提示环境异常，请确认网络正常后重试；登录态只保存在你自己的设备里。断网时不会丢失登录状态，重新联网后会自动恢复。

播放与试听

会员歌曲是否提供试听、可听多久，完全由网易云官方按当前请求状态判定，应用按官方返回的实际秒数显示，不写死任何秒数。登录普通账号或开通会员后可播放的时长同样以官方为准；若某首歌提示「需要登录」，说明官方对该资源未下发试听链接。

音质

未登录、已登录非会员、会员三种状态默认都请求网易云官方支持的最高音质，官方会按账号权限自动降级到可播放的最高档，因此无需手动设置。也可随时切换到较低档位（标准 / 较高 / 极高 / 无损 / Hi-Res / 沉浸环绕 / 超清母带）。实际播放档位以官方返回的 level / 码率为准显示。

音效

播放控制栏可开启音效，共 7 种固定预设：超重低音 / 3D 环绕 / 全景环绕 / 高解析人声 / 清澈人声 / HiFi 现场 / 震撼全景。音效实时生效，戴耳机体验更佳。预设参数为本应用独立调校的公开等效实现，非网易云官方参数。

状态栏媒体模块 / 锁屏控制

应用运行期间（包括切到后台），下拉状态栏可见常驻媒体卡片，支持播放 / 暂停 / 上一首 / 下一首（登录后还有收藏）。锁屏界面同样显示播放控制。从最近任务里划掉应用（完全清后台）后，媒体模块随之消失。

帧率

应用默认使用手机支持的最高刷新率。设置 → 播放 里可切换 30 / 60 / 90 / 120 帧等档位，只显示设备支持的档位，最低 30 帧。

断网与缓存

无网络时打开应用：功能界面正常、登录状态保留，仅联网内容（榜单、搜索、播放）暂不可用并提示离线；恢复网络后自动刷新。已缓存的歌曲离线可继续播放。设置里可清理缓存。

在线更新

应用启动时会自动检查更新，发现新版本可在弹窗里直接下载并覆盖安装（无需卸载）。也可访问站点首页点击「下载软件」获取最新安装包。

搜索历史

长按单条搜索历史会出现「删除」小按钮，点击页面其他位置按钮自动消失。清空全部历史请点搜索框旁的清空按钮。
