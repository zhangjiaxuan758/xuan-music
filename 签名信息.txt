一、音源实现（本版核心）
------------------------
客户端直连网易云官方接口 music.163.com/eapi，不经过任何第三方中转服务：
  - 请求加密：AES-128-ECB + MD5 摘要（eapi 公开协议格式）
  - 登录态：扫码登录后只把 MUSIC_U / __csrf 存在设备本地 localStorage
    （键名 online_provider:netease:cookie），不上传、不外发
  - 无需 AppID / AppSecret / RSA 私钥 / 任何服务端
  - 只保留网易云一个平台，酷狗 / QQ 入口已整体移除

官方受限内容按网易云口径处理，与官方客户端提示一致：
  - 数字专辑 / 付费单曲（fee=1/4）→ 提示购买
  - VIP 专享（fee=8）→ 未登录提示登录、已登录非会员提示开通会员
  - 无版权 / 已下架（code=-110、noCopyrightRcmd、resourceState）→ 提示无版权
  - 地区限制（cannotListenReason）→ 提示地区限制
  - 试听片段（freeTrialInfo）→ 只播可播片段，不伪造完整播放
  - 离线（无网络）→ 统一提示「无网络连接」，不误报为会员问题

三、二次构建步骤
----------------
1. 安装 Node.js 22、JDK 21、Android SDK（platform android-36 / build-tools 36.0.0）
2. 在 android/local.properties 写入 sdk.dir=<你的 Android SDK 路径>
3. 项目根目录：
     npm ci
     npm run build:capacitor
     npx cap sync android
4. cd android && ./gradlew assembleRelease
5. 对齐与签名（必须三步都在）：
     zipalign -P 16 -f 4 app-release-unsigned.apk app-release-aligned.apk
     apksigner sign --ks xuan-music.jks --ks-key-alias xuanmusic \
       --v1-signing-enabled true --v2-signing-enabled true --v3-signing-enabled true \
       --out 小轩音乐_v1.6.5.apk app-release-aligned.apk
     apksigner verify --print-certs 小轩音乐_v1.6.5.apk
6. 验证输出应为：Verified using v1 scheme: true / v2 scheme: true / v3 scheme: true
