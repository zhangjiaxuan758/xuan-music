一、音源实现（本版核心）
------------------------
客户端直连网易云官方接口 music.163.com/eapi，不经过任何第三方中转服务：
  - 请求加密：AES-128-ECB + MD5 摘要（eapi 公开协议格式）
  - 登录态：扫码登录后只把 MUSIC_U / __csrf 存在设备本地 localStorage
    （键名 online_provider:netease:cookie），不上传、不外发
  - 无需 AppID / AppSecret / RSA 私钥 / 任何服务端
  - 只保留网易云一个平台，酷狗 / QQ 入口已整体移除

官方受限内容按网易云口径处理，与官方客户端提示一致：
  - 数字专辑 / 付费单曲（fee=1/4）→ 提示购买
  - VIP 专享（fee=8）→ 未登录提示登录、已登录非会员提示开通会员
  - 无版权 / 已下架（code=-110、noCopyrightRcmd、resourceState）→ 提示无版权
  - 地区限制（cannotListenReason）→ 提示地区限制
  - 试听片段（freeTrialInfo）→ 只播可播片段，不伪造完整播放
  - 离线（无网络）→ 统一提示「无网络连接」，不误报为会员问题


二、10621 版改动清单（在 10620 基础上新增/修复）
--------------------
音效（真实可感知，贴近官方预设）
  - 官方 API 不提供可调音效参数（「鲸云音效」是客户端本地 DSP），因此用 Web Audio
    本地复刻等效频响：低架工作点从 60–70Hz 上移到 110Hz / 160Hz 可听低频区，
    叠加 WaveShaper 软饱和谐波（补足手机扬声器重放不出的基频），
    链路末端 DynamicsCompressor 限幅防削波，兼顾「有效果」与「不发糊」
  - 预设：超重低音 / 低音增强 / 清澈人声 / 现场环绕 / 电子 / 古典，可开关、调强度
  - 切换音效时若 AudioContext 处于 suspended 自动 resume，避免「用了跟没用一样」
音质（网易云官方 level 直连 + 登录 / 会员门槛）
  - 音质档位本来就走官方 /api/song/enhance/player/url/v1 的 level 参数：
    standard=128k / higher=192k / exhigh=320k / lossless / hires 等均为官方码率流
  - 新增 audioQualityGate 模块：未登录默认标准音质；未登录切换高音质时提示登录
    并弹出扫码二维码（播放页首页被卸载，故用 sessionStorage pending 标记 +
    切回首页自动弹窗）；登录成功后恢复用户此前保存的音质偏好
  - 档位归属（无损/Hi-Res=会员、极高=登录）按网易云官方公开口径写在客户端，
    官方不下发这层规则；能否真正播到该码率完全由官方取链接口实时判定
  - 无损 / Hi-Res 需会员：明确非会员时提示且不可用；接口未返回 vipType 时放行，
    避免误伤真会员；有会员则正常使用
  - 未登录取链只请求 standard，不越级请求高码率
  - 会员身份由官方 /api/w/nuser/account/get + /api/nuser/account/get 返回的
    profile.vipType 判定，不是客户端猜测；官方 profile 未带该字段时放行，
    由取链接口做最终判定，避免把真会员误判成非会员
  - 取链档位经 resolveEffectiveQuality 按官方账号态收敛：非会员若设置里
    残留无损 / Hi-Res，直接回落到极高，不向官方发无效的高码率请求
  - 返回的音质档位以官方 br 校准（128001 标准 / 192001、320001 极高 /
    999001 无损 / 1999001 Hi-Res），避免「选了无损、实际拿到 320k 却仍显示无损」
扫码登录
  - unikey 与 check 的 type 由 3（PC 桌面客户端授权）改为 1（移动端 / 网页授权），
    手机 App 扫码不再显示「登录PC版」；登录说明改为「移动端授权」
播放页与设置
  - 双击沉浸模式下隐藏右上角返回按钮（此前常显）
  - 歌曲刚开播、controlsDisabled 短暂为 true 时，点进度条也能立即展开（放大）
  - 设置里「歌词样式」工作台：横屏可滚动；歌词动画 / 背景等分区点击改用
    pointerdown 直接响应，修复「划不动、点了没效果」

五、二次构建步骤
----------------
1. 安装 Node.js 22、JDK 21、Android SDK（platform android-36 / build-tools 36.0.0）
2. 在 android/local.properties 写入 sdk.dir=<你的 Android SDK 路径>
3. 项目根目录：
     npm ci
     npm run build:capacitor
     npx cap sync android
4. cd android && ./gradlew assembleRelease
5. 对齐与签名（必须三步都在）：
     zipalign -P 16 -f 4 app-release-unsigned.apk app-release-aligned.apk
     apksigner sign --ks xuan-music.jks --ks-key-alias xuanmusic \
       --v1-signing-enabled true --v2-signing-enabled true --v3-signing-enabled true \
       --out 小轩音乐_v1.6.5.apk app-release-aligned.apk
     apksigner verify --print-certs 小轩音乐_v1.6.5.apk
6. 验证输出应为：Verified using v1 scheme: true / v2 scheme: true / v3 scheme: true
